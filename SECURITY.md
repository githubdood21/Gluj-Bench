# Security policy

## Supported versions

Security fixes are provided for the latest published Gluj-Bench release.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use the repository’s private **Report a vulnerability** form under the GitHub Security tab:

https://github.com/githubdood21/Gluj-Bench/security/advisories/new

Include the affected version, reproduction steps, expected impact, and any suggested mitigation. Please avoid including unrelated system information or personal data.

Gluj-Bench runs intensive native CPU and GPU workloads. A performance result that differs from an expected score is not by itself a security vulnerability.
